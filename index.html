欢迎使用 Markdown Viewer

这是一个 GitHub 风格的 Markdown 文档浏览器，支持：

  • 打开 / 拖入 .md 文件或整个文件夹；「默认目录 ▾」可打开或设定默认目录
  • 也支持代码 / 配置文件：.txt（纯文本）、.py、.sh / .bash、.js、.json、.yaml、.ini、.conf、.sql、Dockerfile 等，按对应语法高亮显示
  • GFM 渲染：标题、列表、表格、引用、任务列表，支持 <br> 换行与 <font color> 文字颜色
  • 代码块语法高亮，主题配色高度可定制（导入 / 导出、正文字号设置）
  • 右键编辑正文 / 代码块，修改可直接写回磁盘（兼容模式则保存到浏览器缓存）
  • 选中文字上色 / 取消颜色，单击图片可在浏览器中放大查看
  • 全文搜索、文档内跳转、撤销改动、热重载
