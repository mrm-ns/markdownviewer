# Markdown Viewer

一个用于浏览 Markdown 文档的 Web 应用，界面风格参照 GitHub Markdown。

## 功能

- **GitHub 风格渲染**：标题、列表、表格、引用、任务列表等 GFM 基础语法
- **打开文件 / 文件夹**：可以打开单个 Markdown 文件，也可以打开整个文件夹，在侧边栏快速切换文档
- **文档列表右键改名**：在左侧文档列表右键选择“重命名”
- **文档列表 + 当前大纲**：左侧侧边栏可切换“文档列表”和“当前文件大纲”
- **侧边栏折叠/展开**：侧边栏与正文交界处的三角符号可收起或展开侧边栏
- **右键插入文本块 / 代码块**：在正文里补充内容，无需外部编辑器
  - **右键正文块**（段落、标题、列表、表格、引用、代码块）→ 菜单里的「➕ 插入 ▸」二级菜单，内含「⬆️ 上方插入」「⬇️ 下方插入」文本块或代码块（鼠标移到「插入」即展开，右侧空间不足会自动向左 / 向上展开；「缩进」与「插入」两个二级菜单同一时刻只展开一个）
  - **按「行」定位**：右键落在正文的哪一行，插入点就是那一行——「上方插入」= 该行之上，「下方插入」= 该行之下；多行段落内部也能精确插入（如 3 行段落里插在第 2 行下方），列表项、表格单元格、引用块内的段落同理
  - **右键空白处**（正文留白、块之间的空隙、文末下方）→ 「➕ 在此处插入文本块 / 代码块」，按点击位置决定插入点
  - **鼠标划过菜单项即预览插入位置**（是一条带「将在此处插入」标签的蓝色指示线，画在目标行的上下沿，不点击不会改动文档）
  - **空行规则**：只在「插入内容会与相邻行粘成同一段」时才补空行——插入 `- ` 列表项、``` 围栏、`> ` 引用块时两侧都不补（它们本来自成一块），这样新项能直接接进已有的列表，不会把一个列表拆成三个；插入纯文本且紧贴段落时才补，否则会被并进上一段。插在段落**内部**时一律不补，否则会把该段拆成三段
  - **插入时即可选择是否缩进**：编辑框下方有「⇧ 缩进一级（成为上一项的子内容）」勾选项，勾上就相当于插入后立即右移一级，省去再右键一次
    - 只有「插入点上方那一行属于某个列表项」时才可勾选；否则置灰并写明原因（上方是普通段落时缩进是惰性的、渲染毫无变化；上方是围栏代码块时 2 个空格会落进代码内容里，等于改坏源码）
  - 编辑框**从一行起步、随输入自动增缩**（输入到第二行即增高，删回一行即缩回），无滚动条
  - 插入代码块可填写语言（带候选提示）；确认后直接写回磁盘，并可用「↩︎ 撤销改动」撤销
  - 仅对 Markdown 文档提供该功能：代码 / 配置文件整份按纯文本渲染，插入 Markdown 围栏会破坏源码

- **右键调整缩进**：菜单里的「⇥ 缩进 ▸」二级菜单，含「⬅️ 左移」「➡️ 右移」，每次移动**一个层级 = 2 个空格**
  - 配合上面的插入功能使用：先在列表项下面插入 `- 文本` / 代码块 / `> 引用块`（默认与前文平级），再对它们右移一级，就成为上一项的子内容
  - **按整棵子树移动**：列表项连同它下面的子项、续行一起平移，不会把子项拆成同级
  - **可缩进的块**：列表项（含任务列表）、段落、代码块、引用块、表格；**标题不提供**（缩进会把 `# 标题` 变成普通段落），整份代码文件也不提供（会改坏源码本身的缩进）
  - **菜单入口始终可见**：只要该块本身可以缩进就显示「⇥ 缩进」，方向是否可用由按钮置灰体现，鼠标悬停能看到原因（如「上方不是列表项，缩进后不会变成子级」「已经在最左：这一行前面没有空格可减」），不会出现「找不到这个功能」
  - 引用块里的列表会把空格加在 `> ` 之后，引用块自身则加在 `>` 之前，两种情况都能正确升降级
  - 层级以 **2 个空格**为一步；文档若用 4 空格缩进，左移需要点两次
  - 每次缩进都可用「↩︎ 撤销改动」逐步回退

- **右键编辑正文**：编辑段落 / 标题 / 列表 / 引用 / 表格单元格 / 代码块
  - 编辑框高度跟随内容：**单行内容就是一行高**，输入换行即增高、删回即缩回，无滚动条
  - 编辑**引用块**（`>` 块）时编辑框里**不显示 `>` 前缀**（与代码块编辑框隐藏 ``` 同理），保存时原样加回；`>` 之后的缩进会保留，不会丢
  - **编辑时清空一行 = 整行删除**：把某一行内容删光后保存，该行会整行移除（不会留下空行）；引用块例外，仍写回 `>` 前缀行以维持引用结构
- **右键删除块**：菜单底部的「🗑️ 删除」（红色危险项，单独用分隔线隔开）
  - 删除范围是**该块在源码里的完整行**；删嵌套列表的父项会连同子项一起删除
  - **删列表项不会把列表切断**：列表项之间的空行会**一并删除**，删除后上下列表仍是同一个列表
  - 空白处右键不提供删除（没有块可删）；整份代码文件也不提供（会清空整个文件）
  - 删除可用「↩︎ 撤销改动」完整还原

- **主题自动保存**：导入或修改的主题会自动保存，下次打开自动加载上次主题
- **导入主题加入预设菜单**：导入的主题会自动出现在「🎨 主题」预设下拉框中，方便以后切换
- **保存当前主题**：主题面板中新增「💾 保存主题」，可将当前编辑的主题保存到预设主题列表
- **主题操作集中管理**：保存主题、导出主题、导入主题按钮已移入「🎨 主题」面板
- **顶部菜单折叠/展开**：顶部菜单可收起，收起后通过顶部中央的 `▼` 展开
- **热重载当前文件**：顶部「⟳ 刷新文件」可重新加载当前文件，不刷新整个页面
- **全文检索**：搜索框可选择“文件名 / 全文（含标题）”，全文模式在当前工作区所有 Markdown 文件中逐行搜索；命中结果按行展示在侧边栏（文件、行号、所属标题、关键词高亮），点击可跳转到正文对应行
  - **标题也参与搜索**：`# 安装步骤` 这类标题行本身就是命中项，只出现在标题里的关键词也能搜到；标题命中有明确标识（左侧蓝竖线 + 「标题 Hn」标签 + 🏷️ 图标，正文命中为 📑），结果数另标出其中的标题命中条数
  - 结果**按文件分组折叠**：文件名作组标题（右侧小三角 ▸/▾ 提示可展开，另带目录前缀与该文件的命中条数），默认全部收起，点标题行展开 / 收起；改关键词、跳转、打开文件后已展开的文件保持展开
  - 代码围栏内的 `#`（含缩进围栏与引用块内围栏）不会被误当成标题


- **代码语法高亮**：内置轻量高亮，支持 Python / JavaScript / JSON / Bash / Keepalived 等
- **内置 Keepalived 配置语法高亮**：使用 ` ```keepalived ` 代码块即可高亮 LVS/Keepalived 配置
- **Bash 深度高亮**：识别常用命令、软件包命令、LVM/LVS/Systemd 命令、长短选项、符号和行首 `$` 提示符
  - `#` 注释只在**行首或左侧全为空白**时生效（与 shell 语法一致）：`[root@docker ~]# brctl show` 这类 root 提示符不会被误判成注释，`x=1#y`、URL 里的 `#frag` 也不会
  - **`<占位内容>` 分色**：尖括号 `<` `>` 本身用**符号色**，中间的内容用**变量色**（与 `$VAR` 同色），文档里的 `cp <source> <dest>`、`mount <设备> <挂载点>` 一眼就能看出哪段是要替换的占位符
    - 内容按「不含空白的整段」识别，因此 `echo a > x && echo b > y` 这类重定向链不会被误染色；`<<EOF`、`2>&1` 也保持原样
    - `"<b>hi</b>"` 这类出现在引号里的尖括号仍整体按字符串色，不会被二次染色
- **Dockerfile 高亮**：在 Bash 规则基础上扩展 Dockerfile 指令（`FROM` / `RUN` / `LABEL` / `CMD` / `COPY` / `ENV` / `WORKDIR` / `EXPOSE` / `ARG` / `VOLUME` / `HEALTHCHECK` 等，大小写均可），`RUN` 行内的 shell 命令、选项、变量同样高亮；` ```dockerfile ` / ` ```docker ` / ` ```Dockerfile ` 均可
- **Shell 兼容**：`shell` / `sh` / `zsh` / `ksh` / `console` / `terminal` 代码块统一使用 Bash 高亮规则
- **INI / CONF / YAML 深度高亮**：注释、字符串、IP、数字、`$` 变量；INI 区分 `key = value`，CONF 区分 `key value`，YAML 区分 `key: value`
- **XML 高亮**：` ```xml ` 代码块即可高亮；尖括号、标签名、属性名、属性值、注释、`<?xml ?>` 声明、`<!DOCTYPE>`、`<![CDATA[]]>`、实体（`&amp;` / `&#38;` / `&#x26;`）分色显示
  - 着色分工：`<` `</` `>` `/>` 用 **tag** 色（**左右尖括号同色**，一个标签不会花掉），标签名用 **name** 色（比尖括号醒目），属性名用 **attribute** 色，属性值用 **string** 色
  - XML 家族围栏名共用同一套规则：`xml` / `xhtml` / `xsl` / `xslt` / `xsd` / `svg` / `plist` / `rss` / `atom` / `csproj` / `xaml` / `wsdl` / `dtd`
  - 未标注语言的围栏若以 `<?xml` 声明开头，会自动按 XML 高亮
  - 刻意**不**把 `html` 归入 XML：HTML 语法更松（属性可无引号、有自闭合空元素），套 XML 规则会串色
- **多类型文件识别**：除 `.md` 文档外，也可直接打开代码 / 配置文件，按其语法高亮显示（不做 Markdown 解析，源码原样呈现）：
  - `.txt` → 纯文本；`.py` → Python；`.sh` / `.bash` / `.zsh` / `.ksh` → Bash
  - `.js` → JavaScript；`.json` → JSON；`.yaml` / `.yml` → YAML
  - `.ini` → INI；`.conf` → CONF；`.sql` → SQL；`.promql` → PromQL
  - `.xml` / `.xsl` / `.xslt` / `.xsd` → XML
  - `Dockerfile` / `Containerfile`（无扩展名，按文件名识别）→ Dockerfile
  - 注意 `.svg` 仍按**图片**处理（不打开为代码），以便 Markdown 里引用 SVG 能正常显示

- **正文字号 / 代码字号调节**：在主题面板中可分别调整
- **支持原生 HTML / Markdown 图片**：可直接渲染 `<img src="..." width="600">` 和 `![](图片路径)`，打开文件夹时会自动解析相对路径图片
  - **单击图片在当前页面放大查看**：不再新开浏览器标签页，而是弹出全屏遮罩层居中放大显示；点遮罩空白处、按 `Esc`、点右上角 `✕` 三种方式都能关闭
    - 超宽 / 超长图按视口等比约束，不会被裁掉；放大期间背景正文不滚动
    - **`file://` 模式下同样可用**：浏览器只禁止「顶层导航」到本地文件，不禁止页面内 `<img>` 加载本地图片，所以直接用 `index.html` 打开时点图也能放大（旧版在新标签页打开会被浏览器拒绝）
    - 被 `<a>` 包裹的图片仍优先跟随链接（不放大），与 GitHub 等平台行为一致
- **默认目录**：使用“打开文件夹”时，支持 File System Access API 的浏览器会自动记住目录，下次启动尝试自动加载；也可点击“默认目录”按钮手动恢复
- **行内代码与代码块独立配置**：行内代码和代码块可分别设置字号、文字颜色、背景色
- **工作区内部跳转**：支持 `[文字](./其他.md#标题锚点)` 在工作区内切换文档并定位到标题



- **高度自定义代码块配色**：
  - 内置 GitHub Light / GitHub Dark / Atom One Dark / Dracula / Solarized Light / Keepalived Config 等预设
  - 可单独修改关键字、字符串、注释、数字、函数、变量、类型等 42 项颜色
    - 支持高级 CSS 覆盖，可针对具体语言进一步定制（例如 `.language-python .hljs-keyword`）

  - 实时预览
  - 主题可导出 / 导入为 JSON，自动保存在浏览器本地

## 使用方法

本项目是纯静态页面，直接打开 `index.html` 即可使用，**完全离线可用，不依赖任何 CDN**。

也可以启动本地静态服务器：

```bash
# 在项目目录下执行
python serve.py
# 或使用 Python 自带的 http.server
python -m http.server 8000
```

然后访问 <http://localhost:8000>。

### 打开文档

- 点击「打开文件」选择单个 `.md` / `.markdown` / `.txt` / `.py` / `.sh` / `.json` / `.yaml` 等文件
- 点击「打开文件夹」选择整个文件夹，侧边栏会列出其中所有 Markdown 文档与代码 / 配置文件
- 也可以直接把文件或文件夹拖入窗口
- 代码 / 配置文件以代码块视图显示并高亮；`.md` 文档仍按 Markdown 排版渲染

### 自定义代码主题

1. 点击顶部「🎨 主题」按钮
2. 选择一个预设主题，或直接在列表中修改颜色
   - Keepalived 配置可直接选择 **Keepalived Config** 预设，或点击「导入主题」选择 `themes/keepalived.theme.json`

3. 修改会实时应用到代码块，并自动保存到浏览器 `localStorage`
4. 可点击「下载主题 JSON」保存，之后通过「导入主题」复用

## 技术栈

- 原生 JavaScript 内置 Markdown 渲染器（离线可用）
- 原生 JavaScript 内置轻量语法高亮（支持 Keepalived、Python、JavaScript、JSON、XML、Bash 等）
- 纯 CSS 实现 GitHub 风格基础样式
- 不依赖任何 CDN 或外部网络资源
